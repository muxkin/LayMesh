# Open Props 动画优化后续验证（WebKit 暂缓）

本页是 v26 开发批次的历史记录；新的 0.8.0 文件验收见[发布验证](../object-effects-2026-10-19/release-0.8.0/README.zh-CN.md)。

本轮只处理动画与资源使用。保留原作品、原附件和 v24 记录，不发布版本。WebKit 按用户要求不纳入本轮调查或通过率。
新文件 SHA-256：`90f63f148d86d91794c41b767fe2c061cb0dcb03ae7048b6c918c166c3eccb15`。原附件 64 项源码、字体、资源及显示列表逐项相同；没有降低分辨率、删减效果、缩短动画，或新增页数／内存／显存配额。

## 实现变化

- CPU 保留 Skia 绘制的原密度内容，交给 Canvas2D 合成位置、旋转与透明度；删除已转移的 Skia 副本，避免每帧整页像素转换。透明转场采用相同的预乘透明度规则。
- CPU 阴影从实际轮廓直接模糊；仅对严格识别的矩形和圆角矩形用等价轮廓扩张代替整幅形态学处理，任意形状继续使用原路径。背景图案位于单个重复单元内时避免重复中间光栅化。
- 后台准备在效果、子对象、分块边界可恢复和取消；GPU 完成等待按测量成本合并，减少逐块串行等待。前后台仍为独立 Worker 与渲染器。软件 GPU 使用经对照的 CPU／Canvas2D 路径，硬件 GPU 保留 WebGL。
- 硬件首次进入先显示作品真实入口状态，再准备后续动画缓存；作品时钟与动画时长保留。

## 性能目标检查

- optimized-chromium-3840-default：稳定帧提交 P95 超过 60 Hz 的 16.67 ms 预算
- optimized-firefox-3840-default：稳定帧提交 P95 超过 60 Hz 的 16.67 ms 预算

未测边界：WebKit 本轮暂缓；其他 GPU、操作系统和实体屏幕帧呈现不外推为通过。反复往返和退出重开的有限记录不等于无限时长泄漏证明。

诊断中还尝试了合并缩放／位移、背景整数区域拆分和局部重绘。由于跨浏览器收益不稳定或个别页面回退，均未进入交付运行时；相关记录单独保留，不计入优化成果。
