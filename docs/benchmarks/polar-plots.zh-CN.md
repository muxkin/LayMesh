# 极坐标扩展验收与性能实测

[English](polar-plots.en.md) · [功能参考](../polar-plots.zh-CN.md) · [原始记录](polar-plots.json)

本轮实现原生极坐标和雷达图，修复对数统计图基线及跨轴装饰碰撞诊断，并增加可预设警告控制。固定绘图区、负半径翻转、跨零度、物理裁剪和原始值锚点由自动测试核对。

## 验收

- Node 全套：137 项通过，无跳过；Python：18 项通过。
- 画廊：54 份示例与 Notebook 检查通过；Markdown：52 页；静态文档站：52 页、296 处图片引用及站内锚点检查通过。
- 原六份默认绘图：SVG/PNG 文件字节和 PDF 180 DPI 渲染像素与冻结基线一致。
- 六份新增示例均导出 SVG/PDF/PNG，保留可编辑 .lay、Python/JSON 和 inspect 结果；目视检查三种格式。
- 圆形、扇区、内孔、负径向网格及缺失区域使用 PNG/PDF 像素检查；周期填色无重复透明度，文字/公式可从 PDF 提取。
- 图层和锚点使用解析投影；曲线细分局部误差上限 0.001 mm，不抽样原始数据。

## 本机实测
