# 从当前页放映与演讲者视图

放映按钮默认从当前预览页开始，该页的动画从头播放。放映菜单也提供从头窗口放映、从头全屏放映和演讲者视图。退出后恢复原来的预览状态。

主“放映”按钮始终从当前页进入普通全屏，只显示幻灯片；连接多个屏幕也不会自动打开演讲者控制台。菜单保留“窗口放映”“仅幻灯片”“从头放映”和“演讲者视图”。

需要讲稿和控制台时，从菜单手动选择**演讲者视图**。原窗口显示观众画面，新窗口显示控制台，默认均保持窗口状态。先将两个窗口拖到所需屏幕并调整大小，再在观众窗口点击“进入全屏”（或按 F）。窗口位置完全由用户安排；LayMesh 不检测主副屏、不请求屏幕管理权限、不选择目标屏幕，也不自动移动、缩放或交换窗口。

控制台的“前往观众窗口全屏”只定位观众窗口并显示操作提示；须在观众窗口实际点击全屏，不通过消息自动申请。退出全屏后仍保留演讲者会话，方便继续移动窗口。结束放映才关闭附属控制台，并恢复原来的预览页和状态。

弹窗被拦截时，观众窗口提供“打开演讲者控制台”按钮；允许弹窗后点击重试。关闭控制台不会结束观众放映，可从观众窗口重新打开。全屏失败时仍可窗口放映并手动重试。屏幕连接变化不自动调整窗口或关闭控制台，由用户处理。

网页、离线文件和 VS Code 外部浏览器使用同一规则。VS Code 的显式“演讲者视图”入口会在浏览器提示点击开始，以便用户操作打开控制台；普通放映入口仍只显示幻灯片。

观众窗口维护实际播放进度。控制台的上一步、下一步、暂停、重播、黑屏和白屏均操作这一个时间线。演讲计时独立运行，暂停动画不会停止计时；计时可单独暂停或归零。

当前页预览直接接收已绘制的观众画面，包括页间转场，不再重复采样和渲染动画。镜像上限 15 fps、1280 像素宽；复制较慢时自动降为 10 或 5 fps，仅允许一帧传输在途；隐藏控制台时停止镜像。下一页和缩略图复用观众端的 CanvasKit 实例，在空闲时生成。控制台没有第二套动画渲染器，也无需网络或视频编码器。

“页内动画”进度只计算动画本身。最后一步完成即达到 100%；自动播放中额外的末尾停留显示为“等待切页”，保留作品配置的停留时长。已完成、暂停、等待点击、静态页面分别显示，完成后通过“重播本页”再次播放。

启动接口 `startPresentation(view, {mode, fullscreen, startPageId})` 支持 `slides`（默认）和 `presenter`；旧调用中的 `auto` 作为 `slides` 的兼容别名，不再检测屏幕。未指定 `fullscreen` 时，普通放映默认全屏，演讲者视图默认窗口模式。`enterFullscreen()` 仅在当前窗口申请全屏并返回包含 `ok`、`reason` 和可选 `message` 的结果；`toggleFullscreen()` 切换全屏。观众输出 `animationProgress`、`animationStatus`、`holdRemaining`，控制台不再自行从普通动画元数据计算进度。

## 在页面中写备注

在当前页面的 `.lay` 顶层写独立的三引号字符串：

```python
"""
    先介绍这一页的结构。

    再解释图中的关系。
"""
p = canvas(size=(160mm, 90mm))

'''
补充说明按出现顺序合并。
'''
```

只收集独立的三引号纯文本语句。赋值、调用参数、函数体、条件、循环和导入文件中的文字不作为本页讲稿；不执行字符串插值。公共缩进与首尾空行会清除，内部段落保留。演讲中备注只读，在源码中修改后重新放映。

备注通过可选的 `inspection.speakerNotes` 保存，旧作品没有此字段时显示“本页没有演讲备注”。备注不出现在观众画面和 PDF、SVG、图片中；离线作品会携带该文本，便于再次打开演讲者视图。

## 页面预览和绘制动画

播放版左侧显示页面缩略图。拖动分隔条调整宽度，缩略图保持页面比例；可以折叠侧栏，键盘方向键定位并用 Enter 切页。普通放映时隐藏侧栏，退出后恢复。

`draw` 支持线条、曲线、箭头、虚线和复合描边。末端箭头跟随绘制前端，完成态与静态排版一致。对纯填充、零长度或无可见描边对象，编译产生 `W_ANIMATION`，忽略绘制属性，保留对象、其他动画和步骤时序。旧离线文件中缺少中心线数据的对象保留静态显示并提示重新导出。

可运行示例：`examples/animation/presenter/demo.laydoc`。
