LayMesh 0.6.2 adds offline CSS libraries, fixes preview control layout, updates the VS Code toolbar, and shares FFmpeg discovery and installation across VS Code, CLI and Python.

## Changes

- Bundle Animate.css 4.1.1, Bootstrap 5.3.8 and Open Props 1.7.23 in the engine. `stylesheet="@laymesh/animate.css"` works without a project-local copy; configured older engines receive a clear compatibility message. Improve CSS selectors, cascade, units, shadows and editor diagnostics, with bilingual library catalogs and verified examples.
- Load versioned shared preview styles before controls appear. Keep Present and its arrow joined on one row; keep menus inside the preview, with their background, labels and autoplay switch hidden together when closed. Preserve presentation shortcuts and the default hidden floating controls.
- Replace the VS Code preview toolbar with Refresh, Fit/zoom, page navigation, Present/options, Export and More. Animated previews use three small footer buttons: previous step, play/pause and next step. Advanced playback settings remain in More.
- Reuse an existing FFmpeg or install it into the user's persistent private data directory after explicit download confirmation. China locale/timezone and source reachability guide upstream/mirror selection, with fallback, pinned SHA-256 verification, progress, cancellation and concurrent-install protection. VS Code, CLI and Python share the same discovery and installation logic; noninteractive callers must authorize each download explicitly.

## Validation and distribution

Local checks include real VS Code interaction and MP4 export, Python MP4/GIF export, Linux native and Windows executable smoke tests, and Art Direction browser checks at 3840×1840, 1440×1000 and 390×844. Browser coverage includes first load, refresh, delayed CSS, menu bounds/focus, playback, Tab/Escape, window/fullscreen presentation and exit restoration. FFmpeg installation tests cover consent, integrity, fallback, concurrency and cancellation using isolated fixtures.

The release workflow builds and audits five wheels and five stable VSIX packages for Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon. Linux wheel tags record the binary's actual glibc requirement. PyPI retains the existing approval gate; GitHub Release publishes the same reviewed packages and SHA-256 checksums. Marketplace upload remains manual. See the workflow results for platform acceptance and publication status.

LayMesh 0.6.2 加入离线 CSS 样式库，修复预览控件布局，更新 VS Code 工具栏，并统一 VS Code、CLI 和 Python 的 FFmpeg 查找与安装。

## 更新内容

- 引擎内置 Animate.css 4.1.1、Bootstrap 5.3.8 和 Open Props 1.7.23。`stylesheet="@laymesh/animate.css"` 无需项目内的同名文件；配置的旧引擎会收到明确的兼容性提示。完善 CSS 选择器、层叠、单位、阴影与编辑器诊断，补充中英文样式库目录及经过验证的示例。
- 提前加载带内容版本号的共享预览样式。“放映”与下拉箭头保持横向连接；菜单限制在预览区域内，关闭时背景、文字和自动播放开关一起隐藏。保留放映快捷键及默认隐藏的浮动控制栏。
- VS Code 工具栏提供刷新、适应/缩放、页面切换、放映及选项、导出和更多。动画预览底部仅保留上一步、开始/暂停、下一步三个小按钮，高级播放设置放在“更多”菜单。
- 优先复用已有 FFmpeg；缺失时经明确确认下载到用户的持久私有数据目录。根据中国地区语言/时区提示及下载源连通性选择上游或镜像，支持失败切换、固定 SHA-256 校验、进度、取消和并发安装保护。VS Code、CLI、Python 共用查找与安装逻辑；非交互调用必须逐次明确授权下载。

## 验证与发行

本地验证包含真实 VS Code 交互和 MP4 导出、Python MP4/GIF 导出、Linux 原生与 Windows 可执行程序检查，以及 Art Direction 页面在 3840×1840、1440×1000、390×844 下的浏览器检查。覆盖首次加载、刷新、延迟 CSS、菜单边界和焦点、播放、Tab/Escape、窗口/全屏放映及退出恢复。FFmpeg 安装测试使用隔离样例，覆盖确认、完整性、失败切换、并发与取消。

发布工作流为 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 构建并审计五个 wheel 和五个正式版 VSIX。Linux wheel 标签记录二进制实际要求的 glibc 版本。PyPI 沿用现有审批门禁；GitHub Release 发布同一批审核包和 SHA-256 校验和；Marketplace 继续手动上传。各平台验收与实际发布状态以工作流结果为准。
