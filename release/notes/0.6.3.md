LayMesh 0.6.3 adds a complete offline file workbench, image/document export from the browser, and GL Transitions shared by preview and presentation.

## Changes

- Export editable or playback Universal ZIP-HTML and standard ZIP with all runtime modules bundled. The browser can export SVG, multi-page PDF, editable-object PPTX and 12 raster formats. Keep format/file selection short, with 1200 DPI and TIFF LZW defaults; save advanced settings with the work. Exports are independent of the preview viewport, run in a cancellable worker, and never send source or assets to a server.
- Use Headless Tree 1.7.0 for nested and empty folders, multi-selection, drag/drop, inline rename and keyboard navigation. File operations preserve unsaved buffers and update statically resolved references through the language/CSS parsers. Transactions roll back on failure and support undo/redo; dynamic references are listed for review. Add context menus throughout the app content and repair 12×12px editor color widgets.
- Remove whole-catalog font-file scanning. Share cached catalog/search data and common bilingual aliases; read only required or selected fonts. Connecting an installed matching font or importing the original font automatically restores compilation without a replacement binding. Existing explicit substitutions remain intact.
- Bundle GL Transitions 1.74.0 and its pinned SkSL conversion, effect catalog and licenses. Add document/page `transition()` settings with page override > document default > LCSS priority, explicit `none`, parameters and lazy texture resolution. Cache same-source pages by transition configuration. Preview, window/fullscreen presentation and offline HTML share navigation, cancellation and reduced-motion behavior.

## Validation and distribution

Local verification record: [offline export and workbench](https://github.com/muxkin/LayMesh/blob/v0.6.3/docs/benchmarks/web-export-0.6.3.zh-CN.md).

Release checks cover native contracts, image and PowerPoint decoding, offline Chromium/Firefox/WebKit export and workbench flows, vector PDF page sizes, transparent raster samples, 1200-DPI metadata, TIFF LZW, same-font import, navigation and actual VS Code previews. See the committed test scripts and workflow artifacts for executed results. Real Windows cross-machine font authorization and hardware-GPU transition performance require device testing; local transition measurements use software renderers. Browser WebP is lossless; MP4/animated GIF and the full native PDF/WebP tuning options remain available through CLI/VS Code.

Five-platform wheels and stable VSIX packages are built and audited by CI. PyPI retains its human approval gate; GitHub Release follows verified PyPI publication. Marketplace upload remains manual.

LayMesh 0.6.3 加入完整离线文件工作区、浏览器图片／文档导出，以及预览和放映共用的 GL Transitions 页间转场。

## 更新内容

- 导出可编辑／播放版 Universal ZIP-HTML 与标准 ZIP，运行时全部随包携带。浏览器支持 SVG、多页 PDF、保留可编辑对象的 PPTX 和 12 种图片格式。默认 1200 DPI、TIFF LZW；设置随作品保存。导出使用完整排版，独立于预览视口，在可取消 Worker 中执行，无需服务器。
- 使用 Headless Tree 1.7.0 管理嵌套／空目录、多选、拖放、行内重命名和键盘导航。文件操作保留未保存文本，通过语言与 CSS 解析器更新静态引用；失败回滚、支持撤销／重做，动态引用列出影响清单。应用内容区统一右键菜单，编辑器颜色块恢复 12×12px。
- 取消逐字体读取中文名称的全量索引，缓存目录和搜索文本，内置常用中英文别名。只读取作品实际需要或用户选中的字体；连接或导入同款字体后自动匹配并编译，无需手动替换，保留用户已有替代设置。
- 固定 GL Transitions 1.74.0、SkSL 转换产物、完整目录与逐效果许可。`.laydoc` 支持文档默认和逐页 `transition()`：页面显式配置优先于文档默认，文档默认优先于 LCSS，`none` 明确关闭；参数校验、纹理延迟加载及同源不同配置缓存保持一致。覆盖网页、窗口／全屏放映、离线 HTML 的导航、取消及减少动态效果行为。
