# LayMesh 0.8.0

## 中文

本版加入可组合的静态效果和对象级三维，并修复离线编辑器缩放与动画播放中的渲染、调度和资源复用问题。

- 新增 `reflection()`、`soft_edge()` 和 `three_d()`；形状、文字、公式与图片支持厚度、XYZ 旋转、上下斜面、正交／透视、材质和灯光。共享 Rust 网格与光栅化，保留孔洞、图片裁剪、圆角及旧二维挤出接口。
- 提供 `@laymesh/effects.css` 的 30 个预设和可编辑组合示例。显示列表 v3 保留旧列表读取能力，同步 Python、LCSS、补全和中英文文档。
- 修复圆角三维侧面的透明度及颜色条纹：分离几何覆盖与材质透明度，恢复边缘预乘量化损失，按显示密度细分曲线并执行 4×4 覆盖采样。
- 网页缩放丢弃过期结果，操作结束后完整替换当前视口；交互期间整体变换上一帧，避免不同清晰度拼接。缩放不重新编译源码。
- 前台播放与后台准备使用独立 Worker 和渲染器；可用硬件 GPU 参与后台绘制，任务分阶段让出执行权，切页时取消过期任务。菜单与退出不等待页面准备。
- 修正多层阴影范围，复用静态内容和对象缓存；变换、透明度和静止保持阶段避免重复生成几何、阴影与不变画面。软件路径使用原采样密度的 Canvas2D 合成，减少整页 WASM 缓冲与反复像素转换。
- 没有新增页数、内存或显存配额，也没有降低分辨率、删减效果或缩短动画时间。实际资源与驱动数据、缓存估算分别记录。
- SVG、PDF、PPTX 对复杂三维局部栅格化；普通对象继续保留矢量或可编辑文本。三维参数保存在 `.lay`，不导出为 PowerPoint 原生三维参数。旧离线 HTML 需重新导出才能获得新运行时。

**验证边界：** 动画性能记录覆盖 26 页 Open Props 的自然播放、重复遍历、连续操作和离线保存重开。硬件 GPU、软件渲染和浏览器版本分别记录；4K 软件路径仍不能保证 60 Hz，部分冷页面准备仍超过 200 ms。跨后端文字抗锯齿差异保留原始失败记录和独立参考审查，不宣称逐像素相同。LibreOffice 往返与 PowerPoint 实机验收分开记录；没有实测的 PowerPoint 环境不标为通过。详见[本版验证记录](https://github.com/muxkin/LayMesh/blob/v0.8.0/docs/benchmarks/object-effects-2026-10-19/release-0.8.0/README.zh-CN.md)及其中保留的历史对照。

Marketplace 继续手动上传；GitHub Release 提供五个平台的 VSIX、Python wheel 和 SHA-256 校验和。

## English

This release adds composable static effects and object-level 3D, and fixes offline-editor zoom, animation scheduling and retained rendering resources.

- Add `reflection()`, `soft_edge()` and `three_d()` for shapes, text, formulas and images, with extrusion, XYZ rotation, bevels, orthographic/perspective projection, materials and lighting. Native and WASM share the Rust geometry and rasterizer.
- Ship 30 presets in `@laymesh/effects.css`, editable compositions, display list v3 with older-list compatibility, Python/LCSS support, completion and bilingual documentation.
- Fix rounded-side alpha and color stripes by separating geometry coverage from material opacity and recovering premultiplied edge quantization. Refine curves at display density and use 4×4 coverage sampling.
- Reject stale zoom results and replace the complete current viewport after interaction. Transform one committed frame while interacting, without mixing overview/detail resolutions or recompiling source on zoom.
- Run foreground playback and background preparation in separate Workers/renderers, using hardware GPU preparation where available. Yield at preparation boundaries, cancel stale tasks and keep menu/exit independent of page preparation.
- Correct layered-shadow bounds, retain immutable content for transforms and opacity, and skip unchanged hold frames without shortening authored timing. Compose software frames through Canvas2D at the original sampling density to avoid repeated full-frame WASM conversion.
- Add no fixed page, RAM or VRAM quotas; preserve resolution, effects and animation timing. Report actual allocations, process/driver measurements and texture estimates separately.
- Rasterize complex 3D locally for SVG/PDF/PPTX while preserving ordinary vectors and editable text. Keep 3D parameters in `.lay`; native PowerPoint 3D parameters are not exported. Existing offline HTML files need re-export.

**Verification boundary:** The animation records cover natural playback of all 26 Open Props pages, repeated traversal, interaction and offline save/reopen. Hardware and software backends are reported separately. Software rendering at 4K still does not guarantee 60 Hz, and some cold-page preparation exceeds 200 ms. Cross-backend text antialiasing differences retain their original failed comparison and independent reference review. LibreOffice round trips are distinct from actual Microsoft PowerPoint testing; untested environments are not marked passed. See the [release validation record](https://github.com/muxkin/LayMesh/blob/v0.8.0/docs/benchmarks/object-effects-2026-10-19/release-0.8.0/README.zh-CN.md) and its historical comparisons.

Marketplace upload remains manual. GitHub Release provides five-platform VSIX packages, Python wheels and SHA-256 checksums.
