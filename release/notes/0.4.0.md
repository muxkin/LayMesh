LayMesh 0.4.0 adds artistic text and alpha-based effects to the native engine, Python interface, WASM preview and VS Code extension.

- Paint glyphs with gradients and outlines, independently of the text box border; spans retain their local styles.
- Typeset on open paths, bend text into arcs or waves, map it into a perspective quadrilateral, and add two-dimensional vector extrusion.
- Add outer/inner shadows and glow to text, shapes, transparent images and groups.
- Preserve vector subjects in PDF; render only effect layers in overlapping tiles at the selected DPI (default 1200), with explicit resource-limit errors.
- Build five stable VSIX packages automatically. Marketplace publishing is now manual; download the appropriate VSIX from this release and upload it through the publisher portal.
- Stable version tags trigger the audited five-platform PyPI workflow. The existing PyPI approval remains; after upload, the same reviewed artifacts and checksums are published here.

Text on a path requires one nonzero open route and a single line; inline formulas can be warped/extruded but cannot follow a route. Decorative outlines retain their source text as SVG labels and PDF ActualText. Large blur radii may require lower export DPI. Imported SVG retains its existing safe subset.

See [examples and API](https://muxkin.github.io/LayMesh/en/docs/topics/art-effects.html). Wheels and VSIX packages cover Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon. `SHA256SUMS` covers every package in this release.

LayMesh 0.4.0 新增艺术字与基于 Alpha 轮廓的效果，同步原生引擎、Python、WASM 预览与 VS Code 扩展。

- 支持字形渐变和描边，与文字外框分开设置；保留 span 局部样式。
- 支持沿开放路径排字、弧形、波浪、四角透视和二维矢量挤出。
- 文字、形状、透明图片及组合对象支持内外阴影和内外发光。
- PDF 主体保持矢量，仅效果层按所选 DPI 分块渲染，默认 1200 DPI；超出资源预算明确报错。
- 五平台 VSIX 继续自动构建，Marketplace 改为手动上传，可从本 Release 下载对应扩展。
- 稳定版本标签触发五平台 PyPI 审核流程，保留原有人工审批；上传成功后发布同次审核的 GitHub Release 附件与校验和。

路径文字要求单条非零开放路径和单行文字；行内公式支持变形与挤出，暂不支持沿路径排版。艺术字通过 SVG 标签和 PDF ActualText 保留原文。较大模糊半径可能需要降低导出 DPI。导入 SVG 沿用原有安全白名单。

[示例与接口说明](https://muxkin.github.io/LayMesh/docs/topics/art-effects.zh-CN.html)。附件覆盖 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon，`SHA256SUMS` 覆盖全部发行包。
