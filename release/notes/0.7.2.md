# LayMesh 0.7.2

## 中文

本版完善渐变与背景填充：Open Props 原始 30 组配方可在默认 OKLab 和显式 sRGB 下直接使用，渐变下面的背景底色得到保留。

- 补齐线性、径向、圆锥及三种重复渐变，支持布局后几何计算、方向／中心／径向尺寸、长度与角度色标、双位置、硬边、中点提示、缺省与越界色标。
- 补齐 CSS 内建颜色空间、四种色相路径、缺失分量及透明度预乘；保留源颜色精度，插值完成后映射到输出 sRGB。新增 `gradient(css=...)` 与 `conic_gradient(stops, center=(0.5,0.5), angle=0deg)`，旧构造器保持兼容。
- 完善渐变和图片的多层背景，支持底色、cover/contain、位置、双轴平铺、space/round、列表匹配及简写重置；裁切、描边、透明度和阴影在对象层合成。
- 原生、VS Code、网站与离线预览共享已解析的渐变；显示列表升级至 v2，新读取端兼容 v1，并处理增量更新和图片缓存失效。
- SVG、PDF、PPTX 优先保留矢量，必要时按导出 DPI 局部栅格化并保持正常兜底静默。修复 PDF 重复应用 DPI、离线多页 PDF 资源 ID 冲突、复杂色标被导出库稀疏采样，以及 PPTX 填充／描边重叠位置重复施加对象透明度的问题。
- GitHub Pages 新增[渐变对照画廊](https://muxkin.github.io/LayMesh/gradient-gallery.html)，提供 119 例实际画面、中文差异说明、筛选、放大和可下载验证指标。双语手册、API 补全、Open Props 能力目录与可编辑示例同步更新。

**验证边界：** 实现阶段的 119 例跨端对照和 476 页离线 SVG/PDF 导出，相对原生的平滑区域最大通道误差均不超过 3/255。与 Chromium CSS 直接比较的六个语义差异单列；第 18 组在两种插值设置下各有一个平滑像素达到 4/255。暗色第 8、16 组为原配方效果。PDF/PPTX 画面对照使用 Poppler Cairo 与 LibreOffice；实体 GPU 和 Microsoft PowerPoint 本体仍待实机验证。[完整报告](https://muxkin.github.io/LayMesh/docs/benchmarks/gradients-2026-10-19/README.zh-CN.html)保留误差、资源生命周期和性能记录。

Marketplace 继续手动上传；GitHub Release 提供五个平台的 VSIX、Python wheel 和 SHA-256 校验和。

## English

This maintenance release completes gradients and background fills. All 30 original Open Props recipes work directly with default OKLab and explicit sRGB interpolation, and background colors are retained beneath gradient layers.

- Complete linear, radial, conic and repeating gradients, including deferred layout geometry, directions, centers, radial sizes, physical/angular stops, double positions, hard edges, midpoint hints and omitted/out-of-range positions.
- Support built-in CSS color spaces, four hue paths, missing components and premultiplied alpha. Preserve source precision through interpolation before mapping to output sRGB. Add `gradient(css=...)` and `conic_gradient(stops, center=(0.5,0.5), angle=0deg)` while retaining existing constructors.
- Combine gradients and images in layered backgrounds with color, cover/contain, position, two-axis tiling, space/round, list matching and shorthand resets. Apply clipping, stroke, opacity and shadows at object level.
- Share resolved gradients across native, VS Code, web and offline previews. Display list v2 retains v1 reader compatibility and supports incremental updates and image-cache invalidation.
- Preserve representable vectors in SVG/PDF/PPTX; use silent local raster fallback at the selected DPI when necessary. Fix PDF DPI scaling, offline multi-page resource collisions, coarse resampling of complex color stops, and overlapping PPTX fill/stroke opacity.
- Publish a [comparison gallery](https://muxkin.github.io/LayMesh/gradient-gallery.html) with 119 actual cases, explained reference differences, filters, image inspection and downloadable metrics. Update bilingual guides, completion, the Open Props capability catalog and editable examples.

**Verification boundary:** Implementation-stage comparisons cover 119 cross-backend cases and 476 offline SVG/PDF output pages, with smooth-region maximum channel error at most 3/255 relative to native output. Six semantic differences from Chromium CSS are explicitly separated; recipe 18 has one smooth pixel at 4/255 in each interpolation setting. Dark recipes 8 and 16 are intentional. PDF/PPTX readback uses Poppler Cairo and LibreOffice; physical GPU and Microsoft PowerPoint application validation remain pending. The [full report](https://muxkin.github.io/LayMesh/docs/benchmarks/gradients-2026-10-19/README.zh-CN.html) preserves pixel, lifecycle and performance evidence.

Marketplace upload remains manual. GitHub Release provides five-platform VSIX packages, Python wheels and SHA-256 checksums.
