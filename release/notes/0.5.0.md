LayMesh 0.5.0 adds editable PowerPoint export and native code formatting, with distinct file icons for LayMesh and LCSS.

## What's new

- Export `.pptx` from the CLI, Python API, Jupyter magics and VS Code. Each canvas becomes one slide with its original physical size and drawing order.
- Keep ordinary text editable, including characters missing from the exporting machine's fonts. Shapes, strokes, explicit groups, picture resources and supported gradients retain native presentation objects. Formulas use grouped vector outlines; plots retain their constituent shapes and labels.
- Rasterize unsupported effects only in the affected subtree, with `W_PPTX_RASTER` diagnostics. Fallback resolution defaults to 1200 DPI; fonts are not embedded, and presentation applications may substitute them.
- Format `.lay`, `.lcss` and embedded `style { ... }` with **Format Document** or **Format Selection**. Short calls stay compact; long calls and collections expand at `laymesh.format.lineWidth`, default 100 columns.
- Follow editor indentation, newline and `editor.formatOnSave` settings. Preserve literals, units, comments and expression order; verify parse equivalence before editing. Incomplete syntax, cancelled requests and stale document versions produce no edits.
- Show distinct green chart and style icons in light and dark themes, subject to the active file icon theme.

PPTX package checks and LibreOffice rendering/round-trip verification are separate from native Microsoft PowerPoint testing. See the [export guide](https://muxkin.github.io/LayMesh/en/docs/topics/export.html) and [extension guide](https://github.com/muxkin/LayMesh/blob/v0.5.0/extensions/vscode/README.md).

Wheels and stable VSIX packages cover Windows x64, Linux x64/ARM64 and macOS Intel/Apple Silicon. Download the VSIX matching your extension host and use **Extensions: Install from VSIX**. Marketplace uploads remain manual. `SHA256SUMS` covers all ten reviewed packages.

LayMesh 0.5.0 新增可编辑 PowerPoint 导出与原生代码格式化，并为 LayMesh、LCSS 提供可区分的文件图标。

## 更新内容

- CLI、Python API、Jupyter Magic 和 VS Code 均可导出 `.pptx`；每个画布生成一张幻灯片，保留物理尺寸与绘制顺序。
- 普通文字保留可修改文本框，包括导出机器字体缺失的字符。支持的形状、描边、显式分组、图片资源和渐变保留原生对象；公式转为可解组的矢量轮廓，图表保留组成它的形状和标签。
- 无法原生表达的效果仅在受影响子树中局部回退为 PNG，并通过 `W_PPTX_RASTER` 提示。回退分辨率默认 1200 DPI；不嵌入字体，演示软件可能替换字体。
- **格式化文档**与**格式化选区**支持 `.lay`、`.lcss` 及内嵌 `style { ... }`；短调用保持紧凑，长调用与集合按 `laymesh.format.lineWidth` 展开，默认 100 列。
- 缩进、文件末尾及保存格式化遵循编辑器设置。保留字面量、单位、注释及表达式顺序，确认解析含义一致后才修改；语法不完整、请求取消或文档版本变化时不应用编辑。
- 为两种语言提供绿色绘图与样式 SVG 图标，支持浅色、深色界面，显示遵循当前文件图标主题。

PPTX 包检查及 LibreOffice 渲染、往返保存验证不等同于 Microsoft PowerPoint 原生验证。详见[导出指南](https://muxkin.github.io/LayMesh/docs/topics/export.html)与[扩展指南](https://github.com/muxkin/LayMesh/blob/v0.5.0/extensions/vscode/README.md)。

发行包覆盖 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon。下载与扩展宿主匹配的 VSIX，执行**从 VSIX 安装**；Marketplace 继续手动上传。`SHA256SUMS` 覆盖全部十个审核包。
