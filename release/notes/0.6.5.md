# LayMesh 0.6.5

## 中文

本版完善源码编辑后的增量预览和放映准备，保持 `.lay`、LCSS、`.laydoc`、Python API 和 Notebook Magic 的使用方式兼容。

- 原生预览与离线编辑器复用编译会话、实际读取依赖及未变化的绘图对象。属性更新保留可复用的几何、排版和渲染缓存，连续输入只提交最新版本。
- 修复更新离线运行时后沿用旧依赖索引的问题。导出、保存及运行时刷新校验编译器、源码、字体和页面数据，首次局部修改不会因此重编译无关页面。
- 离线编译按页面保持 Worker 归属，当前页优先，其他受影响页按可用并行度执行。起始页就绪即可放映；页面准备与动画分别执行，保存和导出仍要求全稿最新版本成功。
- 页面、资源和绘图缓存按文档生命周期保留和释放，移除固定容量、页数及线程配额。旧配置中的缓存和图片处理配额字段兼容读取并忽略；图片质量和导出精度设置保留。
- WebAssembly 按实际需求扩展并复用线性内存，避免 WebKit 在多个编译和渲染实例共存时反复复制整个堆。关闭文档会释放相应实例。
- 默认输入合并窗口为 30 ms，VS Code 已显式设置的防抖值继续生效。补充 Python、真实 Jupyter 内核、样式更新、文档重排、错误恢复及离线保存的回归检查。
- 修复演讲者适配层将“页面已显示”事件误判为上下文丢失、清空首帧镜像的问题；控制台连接前完成的画面可在接入后直接显示。

性能随作品、浏览器和渲染后端变化；不承诺所有编辑或动画固定在百毫秒内完成。[阶段测量及已知边界](https://github.com/muxkin/LayMesh/blob/main/docs/benchmarks/first-edit-2026-10-16.zh-CN.md)。VS Code Marketplace 仍由发布者手动上传，GitHub Release 提供五个平台的 VSIX 与 Python wheel。

## English

This release completes incremental source previews and presentation preparation while preserving `.lay`, LCSS, `.laydoc`, Python API and Notebook Magic usage.

- Native previews and offline editing retain compilation sessions, actual read dependencies and unchanged drawing objects. Property updates reuse geometry, text layout and rendering caches; rapid edits only commit the latest version.
- Offline runtime refreshes rebuild dependency indexes with the compiler being shipped. Export, save and refresh validate compiler, source, font and page data so a first local edit does not unnecessarily recompile unrelated pages.
- Offline compilation keeps stable page-to-Worker ownership, prioritizes the current page and uses available parallelism for other affected pages. Playback starts when its starting page is ready; background preparation and animation run separately. Save and export still require the complete latest document.
- Document lifecycle replaces fixed cache capacities, page counts and thread quotas. Legacy cache and image-processing quota fields are accepted and ignored; image-quality and export-precision settings remain available.
- WebAssembly memory grows on demand and reuses allocated blocks, avoiding repeated whole-heap copies in WebKit when compiler and renderer instances coexist. Closing the document releases its instances.
- The default input merge window is 30 ms; explicit VS Code debounce settings remain effective. Regression coverage includes Python, real Jupyter kernels, shared-style updates, document reordering, error recovery and offline save/reopen.
- Presenter mode now distinguishes page-visible notifications from context-loss events and retains the first completed frame while the console connects.

Latency depends on the document, browser and rendering backend; the release does not promise fixed sub-100-ms updates or smooth animation on every backend. See the [phase measurements and limitations](https://github.com/muxkin/LayMesh/blob/main/docs/benchmarks/first-edit-2026-10-16.zh-CN.md). Marketplace upload remains manual; GitHub Release provides VSIX packages and Python wheels for all five supported platforms.
