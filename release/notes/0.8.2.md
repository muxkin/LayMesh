# LayMesh 0.8.2

## 中文

- 在 VS Code 静态预览中左击选中对象。同一位置反复左击可从上到下切换重叠对象。右击选中区域可跳到该实例的放置代码。
- 选中对象后显示布局、路径和绘制范围的锚点，以及适用的路径节点和贝塞尔控制点。悬浮时显示源码名称，重合点会列出多个名称。
- 图表默认显示绘图区和轴端等定位点。鼠标靠近某条轴时，展开该轴的刻度、标签和轴线分段锚点。移开后恢复简洁视图。

## English

- Select an object in the static VS Code preview. Repeated clicks at the same position cycle through overlapping objects from front to back. Right-click the selection to open the code that places that instance.
- See layout, path, and ink anchors, along with applicable path nodes and Bézier controls. Hover for source names, including multiple names where anchors coincide.
- Chart selection shows plot-area anchors and axis endpoints. Move near an axis to see its tick, label, and spine segment anchors. Move away to hide those details.
