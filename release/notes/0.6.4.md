LayMesh 0.6.4 improves presentation playback and portable files, with an optional presenter console and precise draw animations for arrowed paths.

## Changes

- **Current-page playback:** the main Present button starts ordinary fullscreen from the previewed page. Windowed presentation, presentation from the beginning and Presenter View remain explicit menu choices. Closing presentation restores the preview state.
- **Manual presenter view:** the original window shows the audience slide; a separate console shows its bitmap mirror, the next page, speaker notes, thumbnails, steps, timers and blackout controls. Arrange windows yourself, then enter fullscreen in the audience window. There is no automatic screen detection, permission request or window placement.
- **Speaker notes:** independent top-level triple-quoted strings in a `.lay` page become read-only notes. Assignments, arguments, nested blocks and imported components are excluded. Notes do not appear on audience slides or static exports.
- **Draw animation:** arrowed lines retain their centerlines, arrowheads follow the drawing front, and the final frame restores the original static geometry. Inapplicable draw effects produce a non-blocking warning without removing the object, its other animations or step timing.
- **Navigation and progress:** playback files have a resizable, virtualized page sidebar. Animation completion reaches 100% when the last step ends; automatic playback still respects authored trailing holds.
- **PDF export:** bounded effect tiles, grayscale shadow masks, resource reuse and acknowledged per-page transfers reduce playback export memory and repeated image conversion. The default remains 1200 DPI; ordinary shape opacity stays vector. Editable files retain the full Rust/WASM exporter, and native VSIX/CLI/Python/Jupyter capabilities remain intact.
- **Portable export size:** playback retains PDF, SVG, PNG, JPEG and TIFF export with shared resources and compact license storage. Editable files retain the full format set. The playback feature increment is checked against a 300 KiB budget; artwork and embedded font sizes remain content-dependent.

## Validation and distribution

Release checks cover native and Python contracts, installed wheels, stable VSIX manifests, offline Chromium/Firefox/WebKit playback, manual startup, popup/fullscreen recovery, thumbnail caches, resource cleanup and the native external-browser entry. Test records state the actual operating-system and GPU coverage; software and virtual-screen tests do not establish physical Windows multi-monitor behavior.

The release workflow builds and audits Linux x64/arm64, macOS Intel/Apple Silicon and Windows x64 wheels and VSIX packages. Publishing requires the existing PyPI approval gate; Marketplace upload remains manual. Preparing packages does not publish a release.

LayMesh 0.6.4 完善放映与离线文件，加入可选的演讲者控制台，并修复带箭头连线的绘制动画。

## 更新内容

- **从当前页开始：**主放映按钮默认普通全屏，从当前预览页开始。窗口放映、从头放映和演讲者视图均有明确菜单入口；退出后恢复原预览状态。
- **手动演讲者视图：**原窗口显示观众画面，独立控制台提供画面镜像、下一页、备注、缩略图、步骤、计时和黑白屏。手动安排窗口，再在观众窗口进入全屏；不自动检测、申请屏幕管理权限或移动窗口。
- **逐页备注：**当前 `.lay` 页面顶层独立的三引号字符串作为只读讲稿。赋值、参数、嵌套语句和导入组件中的字符串不收集；观众画面及静态导出不显示备注。
- **绘制动画修复：**保留箭头连线中心线，让末端箭头随绘制前端移动；完成时恢复原始静态几何。无法应用 draw 的对象产生非阻塞警告，保留对象、其他动画及步骤时序。
- **页面导航与进度：**播放文件提供可调宽度的虚拟缩略图栏；最后一步动画结束即显示 100%，自动播放仍保留作品设置的末尾停留时间。
- **PDF 导出修复：**特效按有界分块处理，阴影使用灰度透明蒙版并复用资源，逐页确认传输，减少内存占用和重复图片转换。默认仍为 1200 DPI，普通图形透明度保留矢量；可编辑版继续使用完整 Rust/WASM，原生 VSIX／CLI／Python／Jupyter 能力保持不变。
- **离线文件体积：**播放版保留 PDF、SVG、PNG、JPEG、TIFF 导出，复用图片资源并合并重复许可文本；可编辑版保留完整格式。播放版功能增量受 300 KiB 检查约束，作品图片和嵌入字体大小仍随内容增长。

## 验证与发行

发布检查覆盖原生与 Python 契约、安装后的 wheel、正式 VSIX 清单、Chromium／Firefox／WebKit 离线播放、手动启动、弹窗／全屏恢复、缩略图缓存、资源释放与原生外部浏览器入口。测试记录明确操作系统与 GPU 的实际覆盖范围，软件渲染和虚拟屏幕测试不代表 Windows 物理多屏验证。

发布流程构建并审计 Linux x64/arm64、macOS Intel/Apple Silicon、Windows x64 五平台 wheel 与 VSIX。PyPI 保留现有人工审批门禁，Marketplace 继续手动上传。准备发行包不等于已经发布。
