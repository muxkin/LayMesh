# LayMesh 0.6.6

## 中文

本版修复放映时诊断警告覆盖作品画面的问题，保持 `.lay`、LCSS、`.laydoc`、Python API 和 Notebook Magic 的使用方式兼容。

- 移除窗口放映、全屏放映和演讲者观众画面左上角的诊断警告框，包括网页中的放映及 HTML/ZIP 离线导出。
- 编辑器和命令行继续报告画布越界等诊断，导出文件继续保留诊断数据。加载失败和重试界面保持可用。
- 修正后的运行时随新导出文件分发；旧导出文件需要重新导出或更新内置运行时。

VS Code Marketplace 仍由发布者手动上传，GitHub Release 提供五个平台的 VSIX 与 Python wheel。

## English

This release fixes diagnostic warnings covering presentation artwork while preserving `.lay`, LCSS, `.laydoc`, Python API and Notebook Magic usage.

- Remove the diagnostic warning box from windowed, fullscreen and presenter audience playback, including website presentations and offline HTML/ZIP exports.
- Keep canvas overflow and other diagnostics in editors and the command line, and retain diagnostic data in exported files. Loading errors and retry controls remain available.
- New exports include the corrected runtime. Existing exports need to be re-exported or have their bundled runtime updated.

Marketplace upload remains manual; GitHub Release provides VSIX packages and Python wheels for all five supported platforms.
