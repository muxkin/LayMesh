`LayMeshTest.ttc` is a small two-face test collection derived from
`examples/assets/DejaVuSans.ttf`. The second face maps the test character
`A` to the `B` outline so the acceptance suite can detect a wrong TTC face
in SVG/PNG. The source font's redistribution license is at
`examples/assets/DejaVuSans.LICENSE`.

`LayMeshTest.otc` is the equivalent two-face CFF/OpenType collection derived
from `tests/assets/GFSNeohellenic.otf`. Its source license is in
`tests/assets/GFSNeohellenic.LICENSE`.
