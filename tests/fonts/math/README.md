# OpenType mathematics test fonts

These unmodified fonts are fixtures for deterministic tests and comparison renders. They are not bundled into LayMesh distribution packages. `manifest.json` records family, version, SHA-256, and the upstream project. Files were copied from the development host at the recorded versions; upstream HEAD may have newer builds.

XITS and STIX use the SIL Open Font License; Latin Modern Math uses the GUST Font License. Copyright and name records remain in the original files. The corresponding license notices are included here.
